# context-gauge

Плагин для Claude Code: панель над полем ввода, на которой всегда видно, сколько занято контекста, как расходуются лимиты, с какой скоростью идёт ответ и во что обходятся сессии.

## Что показывает

- **Контекст** — сколько токенов занято и сколько осталось до автосжатия. Кнопка «Подробно ›» открывает разбивку: системный промпт, инструменты, сообщения и остальное.
- **Лимиты** — окна на 5 часов и на неделю: процент и время до сброса. Есть только при входе через подписку Claude; при входе по API-ключу этой строки нет.
- **Скорость** — пока идёт ответ, примерная скорость в токенах в секунду; после ответа — точная скорость последнего ответа, среднее за сессию и число ответов.
- **Сессия** — стоимость сессии, токены (вход, выход, чтение и запись кэша) и сколько ещё минут держится кэш промпта.
- **Всего** — примерные расходы и токены за все сессии на этом компьютере и за сегодня.
- **Предупреждение о темпе** — плашка сверху, если при текущем темпе лимит закончится раньше сброса. Убирается крестиком до следующего сброса.
- **Строка состояния** — короткая сводка под полем ввода: `контекст 44 % · до сжатия 541 тыс. · $11,68 · 5 ч 17 % · неделя 53 %`.

## Требования

- Claude Code **2.1.308** или новее: в настольном приложении Claude (вкладка Code) или в терминале.
- **Node.js** в `PATH` — для строки «Всего». Без него панель работает, а в этой строке будет написано «нужен Node.js в PATH».

## Установка

В терминале, в сессии Claude Code:

```
/plugin install context-gauge --marketplace marv1n91/context-gauge
```

Из командной строки:

```
claude plugin install context-gauge --marketplace marv1n91/context-gauge
```

В настольном приложении Claude: «+» рядом с полем ввода → **Plugins** → **Add marketplace** → `marv1n91/context-gauge` → **Add plugin**.

## Настройки

По умолчанию показывается всё. Каждую часть панели можно выключить:

- кнопка **⚙** на панели или команда `/gauge настройки` открывают окно с галочками;
- в терминале те же переключатели есть в `/config`, они начинаются с «Панель: …».

Выбор сохраняется в `~/.claude/settings.json` и действует во всех сессиях; уже открытые сессии подхватывают его примерно за 15 секунд.

Команды:

- `/gauge` — скрыть или показать панель целиком;
- `/gauge context` — разбивка контекста;
- `/gauge настройки` — какие строки показывать.

## Как считается «Всего»

Плагин раз в пару минут запускает `scripts/scan.mjs`. Скрипт читает логи сессий Claude Code в `~/.claude/projects` и складывает токены из ответов модели. Стоимость считается по ценам API Anthropic, поэтому это оценка: при подписке вы платите не столько. Прочитанное запоминается в `~/.claude/cache/context-gauge.json`, и следующий подсчёт читает только новые строки. Итоги по логам, которые Claude Code потом удалил, сохраняются, так что «всего» не уменьшается.

Всё считается локально: плагин ничего никуда не отправляет.
